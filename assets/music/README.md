# Reel background music

Drop your own **royalty-free / no-copyright-claim** audio files here (`.mp3`, `.m4a`, `.wav`, `.ogg`)
and the reel maker will use them automatically, rotating through them by reel variant.

If this folder is empty, reels use a **synthesized calm ambient pad** generated on the fly —
royalty-free by construction (it's math, so it can never trigger a copyright claim on FB/IG).

## Where to get genuinely free tracks (verify the license yourself before committing)
- **YouTube Audio Library** (studio.youtube.com → Audio Library) — filter to "No attribution required"
- **Pixabay Music** (pixabay.com/music) — Pixabay Content License, free for commercial use
- **Facebook Sound Collection** (business.facebook.com → Creator Studio → Sound Collection) — free for use *on Meta platforms*, the safest choice for FB/IG reels

Pick calm / ambient / lo-fi tracks. Files committed here are used by the cloud (GitHub Actions),
so keep them reasonably small (a few short loops is plenty).
